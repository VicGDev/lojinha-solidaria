# 🛍️ Lojinha Solidária — oficina "Caçadores de Bugs"

Site **propositalmente cheio de bugs**, criado para uma oficina de extensão universitária que apresenta a carreira de **QA (testes de software)** para estudantes do ensino fundamental e médio.

Os alunos navegam pela lojinha (vitrine, busca, carrinho, cupom, frete e checkout), seguem um roteiro de casos de teste e registram os defeitos que encontrarem.

> ⚠️ Os bugs são intencionais. Não é uma loja real: nenhum pedido é processado e nenhum dado é enviado ou salvo.

## Como usar
- **Online:** acesse o link do GitHub Pages deste repositório.
- **Offline:** baixe o `index.html` e abra no navegador (funciona sem internet, inclusive no celular).
- **Personalizar a escola:** edite o bloco `CONFIG` no topo do `index.html` ou acrescente `?escola=Nome da Escola` ao final do endereço.

## Contexto
Projeto de Extensão Universitária — Análise e Desenvolvimento de Sistemas (UniRitter), programa **Inclusão e Direitos Humanos**. Objetivo: aproximar jovens de escolas públicas das carreiras de tecnologia e discutir acessibilidade digital como direito.
